# Описание проекта: jc1060-zigbee-gateway

## Автономны локальны шлюз Zigbee 3.0 и контролер 2-канального реле на базе платы Guition JC1060P470C

Ссылка на спецификацию в Google Докуметах: [Спецификация проекта в Google Docs](https://docs.google.com/document/d/18wS22gVPCy645Lzne5a_H5EV_GFkMbuEvTJx2xtfK5U/edit)

---

## 1. Назначение и концепция проекта

Прокт **jc1060-zigbee-gateway** преставляет собой встраиваемое решение дя создния локального центра управления умным домом на базе сенсорной HMI-панели Guition JC1060P470C.

Основя цель — обеспечить автономное, быстрое и отказоустойчивое управление 2-канальным Zigbee-модулями реле (2CH Zigbee Switch Module-L) чрез локальный Zigbee-координатор без необходимости подключения к внешним блачным сервисам или сторонним хабам.

---

## 2. Аппаратная архитектура

Система остроена на гетерогенной двупроцесорной архитктуре Espressif:

### 2.1. Основной вычислительный контроллер (Host): ESP32-P4
- **Чип:** ESP32-P4NRW32 (духъядерный 32-битный RISC-V, 400 МГц).
- - **Памяь:** 32 МБ встроеной PSRAM, 16 МБ внешней Flash.
  - - **Экран:** 7.0-дюймовая IPS-матрица с разршение 1024×600 точек, интрфейс MIPI-DSI.
    - - **Сенсорная панель:** Емкостной тачскрин Goodix GT911, подключеный по шине I2C (SDA = GPIO7, SCL = GPIO8).
      - - **Функции:** Отрисока графическог интерфейса пользователя на базе библиотек LVGL v9, обработка сбытий касания, управление бизнес-логикой  хрнение сценаиев.
       
        - ### 2.2. Беспровдной сетевой опроцессор: ESP32-C6
        - - **Чип:** ESP32-C6-MINI-1U-N4 (одноядернй RISC-V, 160 МГц).
          - - **Радиотракт:** Аппаратны трансивер стандарта IEEE 802.15.4 (2.4 ГГц).
            - - **Роль:** Radio Co-Processor (RCP). Выполняет прием и передачу радиопакетов физического и канального уровней (PHY/MAC).
              - - **ежпроцессорная связь:** Высокоскоростной выделенный интерйс UART (UART1 на скорости 460800 бод, P4 TX = GPIO16, P4 RX = GPIO17) с прооколом Spinel.
               
                - ### 2.3. Исполнительное устройство: 2CH Zigbee Switch Module-L
                - - **Форм-фактор:** Компактный встраиваемый модуль реле для подрозетников.
                  - - **Схема включения:** Без нейтрали (No-Neutral / Line Only) с шунтирующим коненсатором, либо с нейтралью.
                    - - **Уравление:** Два независимых релейных выхда (L1 и L2)  возможностью подклюения традционных клавишнх выключателей (S1, S2).

                      ## 3. Архитектура сети и профиль Zigbee 3.0 (ZCL)

                      Шлюз функцинирует в роли **Zigbee Coordinator (ZC)** в соответствии со спецификацией Zigbee Home Automation (ZHA 1.2 / Zigbee 3.0):

                      ### 3.1. Параметры сет
                      - **Частотный канал:** 13 (диапазон 2.4 Гц, минимальный уовень интерференции с Wi-Fi).
                      - - **Безопасность:** Стандартный глбальный кюч Trust Center (ZigBeeAlliance09).
                        - - **Режим сопряжения (Permit Join):** Включается по запросу с экрана на 180 секунд.
                         
                          - ### 3.2. Карта конечных точек (Endpoints)
                          - - **Endpoint 1 (Канал 1 - L1):**
                            -   - ластер On/Off (`0x0006`): Включеие, выключени и переключение состояния реле.
                                -   - Кластер Basic (`0x0000`): Чтение атрибутов устройста (производитль, модель).
                                    - - **Endpoint 2 (Канал 2 - L2):**
                                      -   - Класте On/Off (`0x0006`): Независимое управление торм силовым каналом.

                                          ## 5. Инстукция о сборке и развертванию


### 5.2. Команды сборк и проивки
```bash
# 1. Активация окружения ESP-IDF
. $HOME/esp/esp-idf/export.sh

# 2. Клонирование рпозитория
git clone https://github..git
cd jc1060-zigbee-gateway

# 3. Выбор целевого чипа хоста
idf.py set-target esp32p4

# 4. Сбрка проекта
idf.py build

# 5. Прошивка и мониторинг логов (подключение к порту HIGH SPEED платы)
idf.py -p /dev/ttyUSB0 flash monitor
```

## 6. Важные эксплуатционные рекомендации

1. **Мерцание ветодиодных лап:** Если модуль реле подключен без нейтрали к энергосберегающим лампам мщностью мене 5 Вт, обязательно установите комплектный шунтирующий конденсатор параллельно лампе первого канала (L1).
2. 2. **Маршрутзация команд:** Для пееключения второго канала команды ZCL всегда должны адресоваться на `dst_endpoint = 2`.
   3. 3. **Сохранение сети:** Раздел `zb_storage` в таблице разделов обеспечивает сохранение сетевых табиц и ключей при отключении лектропитания.com/Aidariki/jc1060-zigbee-gateway

                                          - Усановленны фреймворк **ESP-IDF v6.0** (или овее).
                                          - - Python 3.10+ и сбоочные утилиты CMake и Ninja.
